# ⚡ منصة أدواتك (OmniTools Web Portal & PWA)

منصة مجانية ومتكاملة تحتوي على أكثر من 18 أداة يومية تعمل بالكامل داخل متصفح المستخدم بدون إنترنت (PWA Offline) ودون الحاجة لرفع أي ملفات لضمان الأمان والسرعة الفائقة.

## 🛠️ الأدوات المضمنة (Features)

### 🔲 قسم الـ QR Code (QR Studio)
- **استوديو الـ QR Code الذكي**: توليد رموز QR احترافية للروابط، شبكات الواي فاي (Wi-Fi)، أرقام الهواتف، والرسائل مع تخصيص الألوان والتحميل بصيغة PNG.

### 📝 قسم النصوص ومحلل المحتوى (Text Tools)
- **محلل وعداد النصوص الذكي**: إحصاء دقيق للكلمات والحروف، وقت القراءة، أدوات تنظيف وتبديل حالة الأحرف (Title Case, UPPERCASE, camelCase...).
- **مزخرف النصوص والأسماء**: زخرفة بأشكال متعددة للغة العربية والإنجليزية.

### 💻 قسم المطورين والبرمجة (Dev Suite)
- **منسق ومحول JSON & CSV**: تنسيق وترتيب كود JSON، ضغطه، فحص الأخطاء والتحويل لـ CSV.
- **مشفر ومفكك Base64**: تشفير وفك تشفير النصوص والملفات والصور.
- **مولد كلمات المرور والهاشات**: توليد كلمات مرور قوية وحساب تجزئة SHA-256 محلياً.

### 🎨 قسم الألوان والتصميم (Color Studio)
- **استوديو الألوان والتدرجات**: توليد تدرجات لونية (CSS Gradients)، تحويل الصيغ بين HEX و RGB، ونسخ كود الـ CSS فورياً.

### 📄 قسم الـ PDF (PDF Suite)
- **دمج ملفات PDF**: دمج ملفات PDF متعددة في مستند واحد مرتّب.
- **استخراج وتقسيم الـ PDF**: استخراج وتحديد صفحات معينة.
- **تحويل الصور لـ PDF**: تحويل صور JPG/PNG إلى ملف PDF احترافي.

### 🖼️ قسم الصور (Image Studio)
- **ضغط وتقليل حجم الصور**: تقليل الحجم بنسبة تصل إلى 80% مع معاينة مباشرة.
- **قص وتعديل أبعاد الصور**: أبعاد بالبكسل وأبعاد جاهزة (ستوري 9:16، منشور 1:1، يوتيوب 16:9).
- **فلاتر وتأثيرات الصور**: تعديل السطوع والتباين والتشبع والألوان.

### 🎵 قسم الصوتيات (Audio Tools)
- **محول الصيغ الصوتية**: تحويل إلى WAV/MP3 عبر WebAudio API.
- **قاطع الصوتيات**: تحديد توقيت البداية والنهاية واستخراج مقطع صوّتي.

### 📱 قسم السوشيال ميديا والتواصل (Social Suite)
- **مولد بايو إنستغرام**: سير ذاتية مزخرفة ومجهزة بالإيموجي.
- **مولد كابشن فيسبوك وتيك توك**: اقتراح كابشن وهاشتاجات نشطة.
- **مولد رابط واتساب المباشر**: إنشاء رابط `wa.me` مباشر برقم الهاتف.

### 📦 حزم الأدوات (Tool Bundles)
- **حزمة صناع المحتوى**: إعداد المنشور والغلاف والبايو في شاشة واحدة.
- **حزمة المستندات**: تحويل ودمج الـ PDF متتابعاً.

## 💻 التشغيل المحلي (Local Setup)

```bash
# استنساخ المشروع
git clone https://github.com/banzox/ved.git

# الانتقال للمجلد
cd ved

# تثبيت الاعتمادات
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```
